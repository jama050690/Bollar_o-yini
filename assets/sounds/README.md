# Ovoz fayllari

Ilova bu fayllar bo'lmasa ham ishlaydi (ovozsiz). Fayllar qo'shilgach, avtomatik ijro etiladi.
Format: `.mp3`, qisqa (1-2 soniya), o'zbek tilida, bolalarga yoqimli ovoz.

## effects/
| Fayl | Qachon |
|---|---|
| `correct.mp3` | To'g'ri javob |
| `try_again.mp3` | Xato (muloyim, qo'rqitmaydigan ovoz) |
| `win.mp3` | O'yin tugadi |

## uz/numbers/
`1.mp3` ... `10.mp3` — "bir", "ikki", ... "o'n"

## uz/letters/
Harf ovozi. Fayl nomlari:

`a b d e f g h i j k l m n o p q r s t u v x y z` → `a.mp3`, `b.mp3`, ...

| Harf | Fayl |
|---|---|
| Oʻ | `o_.mp3` |
| Gʻ | `g_.mp3` |
| Sh | `sh.mp3` |
| Ch | `ch.mp3` |
| Ng | `ng.mp3` |
